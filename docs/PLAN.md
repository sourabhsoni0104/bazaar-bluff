# War Chest local build
Source: supplied twelve-page Pool, Proposals & Battlefields specification. Video references inform dark dashboard styling, typography, motion, and visual depth.
Build a dependency-free Node server with durable atomic JSON state, server-owned game phases/deadlines, hashed PINs, authenticated team/admin roles, public projection, SSE plus polling, and anonymous role-specific responses. Build a responsive charcoal/ivory/orange command centre and tactical SVG battlefield, team proposal/vote/deployment screens, standings, settings, exports and group creation. Seed clearly marked demo groups and support a guided demo without affecting real groups. Validate worked scoring example, tie/fallback rules, API privacy, validation, and mobile layout. Run locally; do not publish.
Local scope: single Node process; durable state is not a substitute for a production database. CSV team import, drag/drop reassignment, per-group phase overrides and full override editing are deferred and must be disclosed in README.
